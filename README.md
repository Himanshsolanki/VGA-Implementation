A simple VGA controller written in Verilog that displays graphics on a 640 × 480 screen.
Features
- Generates horizontal and vertical sync signals
- Draws simple graphics and patterns
- Written in Verilog HDL
Tools
Vivado, GTKWave
Run
Open the project in Vivado, add the Verilog source files, and simulate or program a compatible FPGA board. Update the timing and pin constraints to match your board and display.
